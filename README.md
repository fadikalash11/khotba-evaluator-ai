# 💍 Smart Khotba Evaluator (Expert System)

نظام خبير (Rule-based Expert System) مصمم لتقييم التوافق في الخطبة بناءً على ضوابط شرعية ومنطقية صارمة.

## 🎯 فكرة النظام
يعتمد هذا النظام على معادلة جدائية تمنع "التعويض الأعمى" للصفات. يطبق شروطاً أساسية كـ (فيتو) يسقط التقييم في حال غيابها (مثل الدين والصلاح)، ويحسب التوافق التراكمي لباقي الصفات بناءً على أوزان يحددها المستخدم.

## ✨ الميزات التقنية
*   **الفلاتر الصفرية (Zero-filters):** إيقاف التقييم فوراً عند غياب الشروط الأساسية.
*   **حواجز الحماية (Guardrails):** منع التقييمات المتطرفة لصفة واحدة من تغطية عيوب كارثية في صفات أخرى.
*   **تخصيص الأوزان (Dynamic Weights):** إمكانية تحديد مدى أهمية كل صفة بشكل منفصل.
*   **تصور البيانات (Data Visualization):** رسم مخطط راداري (Radar Chart) يوضح أبعاد الشخصية.
*   **توليد التقارير (PDF Export):** إنشاء تقرير PDF منسق بجدول وألوان جاهز للطباعة.

## 🛠️ التقنيات المستخدمة
*   Python
*   Streamlit (UI & State Management)
*   Plotly (Radar Charts)
*   PDFKit & wkhtmltopdf (Report Generation)
